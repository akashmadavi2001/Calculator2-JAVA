# 🧮 Calculator Java

A simple and user-friendly **Java Calculator Application** developed using NetBeans IDE. This project demonstrates the implementation of basic mathematical operations using Java programming.

## 🚀 Live Demo

[Click here to use the Calculator](https://akashmadavi2001.github.io/Calculator2-JAVA/)

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚡ Simple and easy-to-use calculator interface
- 💻 Developed using Java

## 🛠️ Technologies Used

- Java
- NetBeans IDE

## 🎯 Project Objective

The main objective of this project is to practice Java programming concepts and understand how mathematical operations can be implemented through a calculator application.
